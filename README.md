# Sudoku Solver

Welcome to this full-stack Sudoku Solver project!  
This project allows you to solve Sudoku puzzles using **image processing** and **backtracking**.

---

## How to Run

You need to run **frontend** and **backend** in separate terminals. The instructions below assume you are using **VS Code**, but you can use any terminal (PowerShell, Command Prompt, etc.).

### 1. Frontend

1. Open a terminal and navigate to the frontend folder:
   ```bash
   cd Frontend

2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
3. Start the frontend:
   ```bash
   npm run dev
   ```
4. A URL will be displayed in the terminal. Press Ctrl + Click to open it in your browser.

### 2. Backend

1. Open another terminal and navigate to the backend folder:
   ```bash
   cd Backend
2. Install dependencies (if not already installed):
   ```bash
   pip install -r requirements.txt
3. Start the backend server:
   ```bash
   python app.py

The backend will now run locally, ready to receive requests from the frontend.

## Testing the Project

-You can test the project by uploading your own Sudoku images.

-A set of 10 sample unsolved Sudoku images is included in the test_images folder for easy testing.

##Features

1)- Upload or drag-and-drop Sudoku images
2)- Automatically detect Sudoku grid using image processing
3)- Solve Sudoku using Python backtracking solver
4)-Interactive React frontend displaying the solution

##Tech Stack

-Frontend: React, JavaScript, HTML, CSS
-Backend: Python, Flask, OpenCV, TensorFlow
-Deployment: Local
